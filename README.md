Banking Transaction Analysis Using SQL & Power BI

1. Overview

This project analyzes banking transaction data using SQL and Power BI to uncover meaningful financial and business insights. It focuses on transaction performance, high-value and abnormal spending, suspicious transactions, and loan risk analysis, helping transform raw banking data into actionable insights for data-driven decision-making.

2. Tech Stack

- 📊 Power BI Desktop – Used to create interactive dashboards and visualize banking insights.

- 🗄️ SQL (MySQL) – Used for data cleaning, querying, filtering, joins, aggregations, and transaction analysis.

- 🔗 Data Modeling – Created relationships between multiple banking tables to enable accurate analysis and cross-filtering.

- 📁 File Format – The project includes SQL files, raw datasets, Power BI dashboard files, dashboard screenshots, and project documentation.

3. Data Source

- Dataset: Banking Transaction Dataset
- Source: Kaggle
- Tables: 10
- Data Type: Banking and Transaction Data

The dataset contains multiple tables related to customers, accounts, transactions, loans, and other banking information used for analysis.

4. Key Features & Highlights

🔹 Business Problem

Banks generate large volumes of transaction data every day. Identifying important transaction patterns, abnormal spending, suspicious activities, and loan-related risks from raw data can be challenging.

This project analyzes banking data to uncover meaningful patterns and provide insights that can support better financial and business decisions.

🔹 Project Goal

The main goal of this project is to analyze banking transaction data using SQL and present the insights through interactive Power BI dashboards.

The analysis focuses on four key business areas:

- 📊 Transaction Performance Analysis
- 💰 High-Value & Abnormal Spending Analysis
- 🚨 Suspicious Transaction Analysis
- 🏦 Loan Risk Analysis

🔹 Dashboard Walkthrough

📊 Executive Overview & Transaction Performance

- Provides an overview of overall transaction activity.
- Analyzes transaction volume and transaction amounts.
- Highlights important transaction performance trends.
- Helps understand the overall execution and performance of banking transactions.

💰 HIGH-VALUE & ABNORMAL SPENDING ANALYSIS

- Identifies high-value transactions.
- Highlights abnormal spending patterns.
- Helps analyze unusual transaction behavior.
- Supports identification of transactions requiring further investigation.

🚨 Suspicious Transaction Analysis Dashboard

- Identifies potentially suspicious transactions.
- Analyzes transaction patterns based on selected risk conditions.
- Helps highlight unusual or potentially fraudulent activity.
- Provides a clearer view of transaction-level risk.

🏦 Loan Risk Analysis Dashboard

- Analyzes loan-related customer information.
- Identifies indicators associated with loan risk.
- Helps understand customer financial behavior.
- Supports data-driven loan risk assessment.


💡 Business Value

This dashboard enables businesses and financial institutions to:

- Monitor overall transaction performance.
- Identify high-value transactions.
- Detect abnormal spending patterns.
- Identify potentially suspicious transactions.
- Analyze customer transaction behavior.
- Understand loan-related risk indicators.
- Support data-driven financial decisions.

6. Key Insights

- 📊 Transaction performance can be evaluated using overall transaction volume and transaction amounts .Transaction Performance: Processed 49K transactions ($121.48M) averaging $2.54K, with stable performance through 2023 followed by a steep drop-off .High-value transactions can be identified for detailed analysis.
- ⚠️ Abnormal Spending: Identified 3.34K high-value transactions, featuring high volatility and a peak single spike of $384.69K.
- 🚨 Suspicious Activity: Flagged 14.318K transactions ($51.66M), driven primarily by unusual spending behavior and categorized largely under high-risk tiers.
- 🏦 Loan Portfolio Risk: Covers 330 loans, where 72.4% are active and 10.3% (34 accounts) are overdue, concentrated among specific high-balance accounts
